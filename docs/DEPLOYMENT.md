## 2. Environment Variables Specification

Ensure the following environment variables are configured in production hosting (e.g. Vercel Project Settings):

```bash
# Application Domain
NEXT_PUBLIC_APP_URL=https://digitalheroes.golf

# Supabase Credentials (Server & Client)
NEXT_PUBLIC_SUPABASE_URL=https://[YOUR_PROJECT_REF].supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=[YOUR_PUBLIC_ANON_KEY]
SUPABASE_SERVICE_ROLE_KEY=[YOUR_SERVER_ONLY_SERVICE_ROLE_KEY]

# Stripe Live Keys (Server-Side Only for Secret Keys)
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_[YOUR_STRIPE_PUBLISHABLE_KEY]
STRIPE_SECRET_KEY=sk_live_[YOUR_STRIPE_SECRET_KEY]
STRIPE_WEBHOOK_SECRET=whsec_[YOUR_STRIPE_WEBHOOK_SECRET]

# Stripe Price IDs
NEXT_PUBLIC_STRIPE_MONTHLY_PRICE_ID=price_[MONTHLY_499_INR_ID]
NEXT_PUBLIC_STRIPE_YEARLY_PRICE_ID=price_[YEARLY_4999_INR_ID]

# Platform Financial Defaults
DEFAULT_CURRENCY=INR
DEFAULT_PRIZE_POOL_PERCENT=50
```

## 3. Supabase Database & Storage Provisioning

### 3.1 Migration Sequence
Run all migrations in order using Supabase CLI or the SQL Editor:
1. `supabase/migrations/0001_foundation.sql` (Extensions & platform settings)
2. `supabase/migrations/0002_profiles.sql` (Profiles & RBAC enum)
3. `supabase/migrations/0003_charities.sql` (Charity directory & events)
4. `supabase/migrations/0004_plans_and_subscriptions.sql` (Subscription plans & status)
5. `supabase/migrations/0005_payments_and_donations.sql` (Payment ledger & idempotency)
6. `supabase/migrations/0006_scores_and_triggers.sql` (Stableford constraints & 5-score window triggers)
7. `supabase/migrations/0007_draws_and_simulations.sql` (Draw state machine & snapshots)
8. `supabase/migrations/0008_winners_and_payouts.sql` (Winner records & review queue)
9. `supabase/migrations/0009_storage_buckets.sql` (Private storage bucket for winner proofs)
10. `supabase/migrations/0010_audit_log.sql` (System-wide audit trail)
11. `supabase/migrations/0011_publish_draw_atomic.sql` (Transactional atomic publishing RPC)
12. `supabase/seed.sql` (Seed verified partner charities and default plans)

### 3.2 Private Storage Bucket
Ensure the `winner-proofs` bucket is marked **Private** with no public read access. Access is strictly granted via 15-minute signed URLs generated by `WinnerService`.

## 4. Stripe Production Setup

1. **Create Products & Recurring Prices:**
   - **Monthly Hero Plan:** ₹499.00 / month (`INR`, recurring monthly).
   - **Yearly Hero Plan:** ₹4,999.00 / year (`INR`, recurring yearly).
2. **Configure Stripe Webhook Endpoint:**
   - **URL:** `https://digitalheroes.golf/api/webhooks/stripe`
   - **Events to subscribe:**
     - `checkout.session.completed`
     - `invoice.payment_succeeded`
     - `customer.subscription.updated`
     - `customer.subscription.deleted`
3. **Copy Webhook Signing Secret (`whsec_...`)** into `STRIPE_WEBHOOK_SECRET`.
